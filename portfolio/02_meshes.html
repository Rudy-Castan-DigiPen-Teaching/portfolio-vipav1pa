Project Procedural Meshes

3D Graphics

Project Overview

The objective of this project was to implement procedural mesh generation algorithms for 3D geometric primitives and integrate them into an interactive graphics demo using OpenGL 3.3 and WebGL 2. This procedural generation framework forms the basis for dynamic 3D asset generation in a custom graphics engine.

Tasks Completed

  • Added new source files (D02ProceduralMeshes, Material, Mesh) and updated CMakeLists.txt.
  • Registered the new demo in DemosFactory with the display name "Procedural Meshes" and short name "meshes" using a lambda function.
  • Implemented core mathematical algorithms in Mesh.cpp, specifically build_index_buffer() and create_plane_vertices().
  • Correctly implemented procedural generation logic for 6 key 3D primitives: Plane, Cube, Sphere, Torus, Cylinder, and Cone.
  • Utilized GL:: wrappers for all OpenGL calls and adhered to strict coding standards, including removing all TODOs and adding proper header comments (Author: Seungmin Hong, Course: CS250, Term: Spring 2026, DigiPen Copyright).

Reflection

The main challenges in this project revolved around the mathematical complexity of mapping 2D UV coordinates to 3D spaces for curved shapes like spheres. It was a valuable structural lesson to manage a multi-demo architecture within a single engine ecosystem, adapting the codebase seamlessly from the previous single-quad setup. On a personal level, there was an incredibly rewarding feeling in seeing raw mathematical formulas transform into perfectly shaded 3D geometric shapes spinning smoothly on both desktop and web-release builds.
